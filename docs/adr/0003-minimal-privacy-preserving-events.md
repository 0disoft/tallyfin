# ADR 0003: 최소·프라이버시 우선 이벤트

상태: Draft(계획). 구현/검증되지 않음. 활성화 전 미결정 항목 확정 필요.

## 결정
경계가 정해진 최소 메타데이터와 카운터만 수집한다. 원시 입력·결과·콘텐츠는 수집하지 않는다.

## 허용 목록
- 프로젝트 ID(라우팅 메타데이터, 비밀/인증 아님)
- tool, locale, mode
- 이벤트명(경계 enum), 오류/필드(경계 enum)
- 카운터, 스키마 버전

알 수 없는 속성은 거부한다.

## 금지 목록
원시 입력/결과/텍스트/건강·금융 정보/이메일, 전체 URL 쿼리·해시·리퍼러 경로, DOM, 세션 리플레이, 핑거프린트, 영속 식별자, 분석 쿠키, localStorage/sessionStorage. 요청 본문 로그 금지.

## 일시적 보호
보호 목적의 일시적 요청 IP는 분석 저장이 아니며, 활성화 전 정책 확정이 필요하다.

## 집계 한계
봇/스팸/차단/전송 누락으로 정확도를 보장하지 않는다. 정확한 고유/재방문 사용자 수, 전체 크로스페이지 퍼널, 어트리뷰션은 초기 범위 밖.

## 보존
일별 집계 우선. 원시 데이터 보존은 정당화·경계가 필요하며 기간은 미결정. 활성화 전 확정한다.

## 관리자 접근
관리자 인증과 프로젝트별 권한이 필요하며 메커니즘은 미결정. Sembom 토큰을 차용하지 않는다.
