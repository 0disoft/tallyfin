# 패키지 소유권

상태: 계획. npm 스코프는 미결정.

## 책임
- core: 프로젝트별 이벤트/속성 등록 정의, 검증, 목표·집계 기준. 특정 서비스 이벤트명을 전역 요구사항으로 두지 않는다.
- browser: 최소 SDK. 동기 수집 I/O 없음, 렌더링/계산 대기 없음.
- storage-d1: D1 집계 저장 어댑터.
- collector: Worker 수신 경계. 프로젝트·스키마·발행 출처에 맞춰 검증하고 집계한다.
- admin: 프로젝트별 조회·이벤트 분석·목표/작업 흐름·설정. 프로젝트 설정과 조회는 권한 검사를 거친다.
- 서비스별 연동: 각 서비스 저장소 소유. Sembom은 첫 예시이며 다른 서비스의 연동 코드를 대신하지 않는다.

## 공개/비공개 통합
공개 프로젝트 ID는 라우팅 메타데이터이며 비밀/인증이 아니다. 비공개 ZDP/Cloudflare 의존성은 core/SDK에 넣지 않는다.

## 기준 문서
제품 범위는 제품 명세, API 형식은 OpenAPI, 저장 구조는 DBML을 따른다. v0.1 계약은 [ADR 0005](../adr/0005-event-and-aggregation-contract.md)에 확정했으며 코어 검증·저장 구현은 후속이다. tools/contracts는 개발 전용 계약 검사이며 core/SDK의 런타임 의존성이 아니다.

## 버전 계획
이벤트에 스키마 버전을 포함한다. 패키지 버전/배포 방식은 미결정.
