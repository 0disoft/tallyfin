# 로드맵 — Tallyfin

상태 표기: 계획 / 착수 안 함. 현재 문서 슬라이스만 초안 작성되었고 나머지는 시작하지 않았습니다.

작은 순차 슬라이스로 진행합니다.

1. **문서** — 현재 슬라이스. 초안 작성됨.
2. **범용 계약 + 코어** — `api/openapi.yaml`/`db/schema.dbml` 예제 교체. 프로젝트별 이벤트·속성 등록, 스키마 버전, 목표/작업 흐름, 전송 출처, 권한과 집계 기준을 확정한다. 착수 안 함.
3. **공통 브라우저 SDK** — 범용 수집·배치 전송과 서비스별 연결 지점을 구현한다. Sembom 전용 이벤트는 SDK에 내장하지 않는다. 서버 발행 이벤트는 계약에서 출처를 구분하고 별도 연동 구현은 후속으로 둔다. 착수 안 함.
4. **Worker 수집기** — 프로젝트별 검증·한도·중복 제거·집계와 실패 격리를 구현한다. 착수 안 함.
5. **핵심 화면 설계·관리자 구현** — 프로젝트 목록/개요, 이벤트 분석, 목표·작업 흐름, 설정 화면을 샘플 데이터로 확인하고 필요한 조회 기능을 구현한다. 임의 다단계 퍼널은 후속 설계다. 착수 안 함.
6. **첫 파일럿** — Sembom에 적용하여 비용·누락·집계 기준을 확인한다. 적용 예시는 [Sembom 연동](../integrations/sembom.md)을 따른다. 착수 안 함.
7. **다른 서비스 파일럿·안정화** — 계산 흐름과 다른 서비스 한 곳에서도 확인한다. 대상은 미정이며, 특정 제품 필드에 종속된 부분을 찾아 수정한다. 서버 연동·다단계 퍼널·저장 어댑터 확장은 필요와 측정 결과에 따라 별도 작업으로 진행한다. 착수 안 함.
8. **라이선스/오픈소스 준비** — 라이선스 결정 및 공개 준비. 착수 안 함.

실행 구현은 필요한 계약을 확정한 뒤 진행합니다. 화면 설계는 샘플 데이터로 미리 검토할 수 있습니다. 계획된 패키지 폴더는 아직 생성되지 않았습니다.
