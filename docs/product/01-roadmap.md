# 로드맵 — Tallyfin

상태 표기: 계획 / 착수 안 함 / 샘플 구현 완료 / 로컬 구현·검증 완료. 문서 초안과 관리자 화면 프로토타입을 작성했고 코어·저장 어댑터·최소 수집기의 로컬 구현을 마쳤습니다. 운영 조회 런타임과 배포는 아직 시작하지 않았습니다.

작은 순차 슬라이스로 진행합니다.

1. **문서** — 현재 슬라이스. 초안 작성됨.
2. **범용 계약 + 코어** — OpenAPI·DBML 예제 교체와 프로젝트/이벤트/속성/작업 흐름·중복·보존·권한 계약 확정 완료. `packages/core`(검증·정규화·해시)와 `packages/storage-d1`(D1 원자 저장·CAS·할당량·정리)를 로컬 구현·검증 완료. 실제 인증과 운영 배포는 착수 안 함.
3. **공통 브라우저 SDK** — 범용 수집·배치 전송과 서비스별 연결 지점을 구현한다. Sembom 전용 이벤트는 SDK에 내장하지 않는다. 서버 발행 이벤트는 계약에서 출처를 구분하고 별도 연동 구현은 후속으로 둔다. 착수 안 함.
4. **Worker 수집기** — 프로젝트별 검증·한도·중복 제거·집계와 실패 격리를 구현한다. 최소 브라우저 수집기(`apps/collector`)와 HTTP 경계를 로컬 구현·검증 완료. 만료 정리 스케줄러·운영 배포는 착수 안 함.
5. **핵심 화면 설계·관리자 구현** — 프로젝트 전환/개요, 이벤트 분석, 목표, 설정의 [샘플 프로토타입](../../prototypes/admin/README.md) 구현 완료. 실제 조회 API·권한 연결은 착수 안 함. 임의 다단계 퍼널은 후속 설계다.
6. **첫 파일럿** — Sembom에 적용하여 비용·누락·집계 기준을 확인한다. 적용 예시는 [Sembom 연동](../integrations/sembom.md)을 따른다. 착수 안 함.
7. **다른 서비스 파일럿·안정화** — 계산 흐름과 다른 서비스 한 곳에서도 확인한다. 대상은 미정이며, 특정 제품 필드에 종속된 부분을 찾아 수정한다. 서버 연동·다단계 퍼널·저장 어댑터 확장은 필요와 측정 결과에 따라 별도 작업으로 진행한다. 착수 안 함.
8. **라이선스/오픈소스 준비** — 라이선스 결정 및 공개 준비. 착수 안 함.

실행 구현은 필요한 계약을 확정한 뒤 진행합니다. 화면 설계는 샘플 데이터로 미리 검토할 수 있습니다. `packages/core`·`packages/storage-d1`·`apps/collector`를 생성했고, `packages/browser`·`apps/admin`·`examples/sembom`는 아직 생성하지 않았습니다.
