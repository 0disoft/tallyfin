# 위험 등록부 (03)

상태: Draft(초기 계획). 아래 완화책은 계획이며 구현/검증되지 않았다. 미결정 항목은 다음 API 슬라이스에서 확정한다.

| 위험 | 설명 | 완화(계획) | 미결정 |
| --- | --- | --- | --- |
| 누락 | 탭 종료/차단/전송 실패로 유실 | 배치 재시도, 멱등성, 탭 숨김 시 전송 | 재시도 횟수, 배치 주기 |
| 중복 | 재전송으로 중복 집계 | 배치 idempotency, 중복 제거 | 중복 제거 TTL |
| 스팸 | 공개 프로젝트 ID·origin 게이트는 봇 방지 불가 | 레이트 리밋, 입력 제한 | 차단 메커니즘 |
| 프라이버시 | 원문/결과/URL/식별자 저장 위험 | 허용 필드만 수집, 금지 목록 | 일시적 IP 정책 |
| 카디널리티 | 자유 텍스트/등록 속성의 조합 폭증 | 프로젝트별 자료형·값·속성 개수·조합 한도 | 프로젝트별 예산 |
| 프로젝트 격리 | 설정/집계/캐시에서 다른 서비스 데이터 노출 | 설정·수집·조회 경계에서 프로젝트 검사, UI 캐시 분리 | 인증·권한 방식 |
| 의미와 버전 | 이름이 같은 이벤트라도 서비스별 정의가 다름 | 프로젝트·정의 버전·발행 출처를 분리, 호환되지 않는 비율 비교 금지 | 스키마 변경 정책 |
| 코호트 | 원시 이벤트 나눗셈으로 완료율 오도 | 등록된 시작·성공 기준과 동일 집계 대상 사용 | 작업 흐름·시간 기준 |
| 발행 출처 | 브라우저와 서버가 같은 성공을 중복 기록 | 이벤트별 확정 출처 지정, 전송 재시도 중복 제거와 의미 중복 구분 | 서버 발행 계약 |
| 연결 한계 | 단기 메모리 집계를 실제 사용자 퍼널로 오해 | 같은 메모리 작업 흐름의 완료율로 표시, 새로고침/기기 간 연결 미지원 안내 | 후속 퍼널 범위 |
| 저장 | 여러 서비스가 공유하는 D1 쓰기 부하 | 일별 집계 우선, 프로젝트별 한도와 부하 측정 | 원시 보존 여부/기간 |
| 벤더 | 수집/저장 구현의 Cloudflare 의존 | core/SDK 비의존 어댑터 | 다른 호스팅 환경의 저장 어댑터 |
| 라이선스 | 오픈소스 의도이나 미정 | 라이선스 확정 전 배포 금지 | 라이선스 종류 |

프라이버시 세부는 [ADR 0003](../adr/0003-minimal-privacy-preserving-events.md) 참조. 정확도 보장 없음.
