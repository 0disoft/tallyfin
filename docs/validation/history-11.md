## Server SDK without dependencies — 2026-10-11

Implemented a separate ESM SDK, `createTallyfinServer`, in `packages/server`. It validates names, properties, UUIDs, and UTC times against the reviewed server-event rules and freezes returned events and properties. The caller awaits the `send` result and sends one batch of 1–20 events up to 16KiB. It has no automatic queue, DOM, or background sending, and retries reuse the originally created body, event IDs, and occurrence times. Tokens are obtained afresh from the host callback on every attempt. It does not automatically retry credential failures or permanent 4xx responses; 408, 429, 5xx, and network/response failures are bounded by attempt count, total time, and cancellation. If `Retry-After` exceeds the budget, it returns retry control to the host instead of waiting a long time. The single-request time limit includes token acquisition, request, and response reads.
