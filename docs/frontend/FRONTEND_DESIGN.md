# 프론트엔드 설계 — 관리자 대시보드

상태: 계획. 프레임워크/라우트/인증은 미결정. SDK에는 UI가 없다.

## 화면 개요
프로젝트별로 기간(date), 도구(tool), 로케일(locale) 기준 집계를 표시한다.
- 카운터: 이벤트별 수치
- 코호트 완료율: 입력 시작 방문 중 성공 방문 비율(동일 코호트/시간 기준). 분모가 없으면 "알 수 없음".
- 오류: 경계 오류/필드 enum 집계
- 피드백: 성공한 제출 수. 평점·버그 내용은 소비 제품의 기존 피드백 시스템이 맡는다. 개별 방문을 추적하는 링크는 만들지 않는다.

## 상태 소유권
조회 상태는 서버 응답이 원천. 클라이언트 파생 상태는 최소화한다.

## 상태 처리
- loading(로딩)
- empty(비어 있음)
- unknown(알 수 없음): 분모 없음
- stale(오래됨): 마지막 갱신 시각 표시
- error(오류)

## 접근/격리
- 관리자 인증과 프로젝트별 권한 필요(메커니즘 미결정).
- 프로젝트 격리: 다른 프로젝트 데이터 노출 금지.
- 키보드 탐색 지원, 최소 320px 폭 대응.

## 미결정
프레임워크, 라우트 구조, 인증 방식. SDK는 UI를 포함하지 않는다.
